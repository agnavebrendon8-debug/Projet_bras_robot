# Projet_bras_robot
Ce projet consiste en la conception et la programmation d’un bras robotique à 4 degrés de liberté capable d’exécuter des tâches selon le programme embarqué.  Le système permet de contrôler précisément les mouvements de l’effecteur afin de réaliser des opérations variées telles que le dessin, le tri d’objets et le contrôle de trajectoires dynamiques
